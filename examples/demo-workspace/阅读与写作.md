# 墨卷 · 把注意力还给文字

写作是一件需要**安静**的事。工具应当退到后面，只留下文字本身。这篇文章用来检验排版：标题、列表、表格、代码、图片、引用，都在下面。

## 为什么是纯 Rust

选择原生渲染而不是套一层浏览器，原因很直接：

1. 启动快，冷启动不到 **200ms**
2. 内存占用低，空窗口大约 60MB
3. 安装包小，没有运行时依赖

> 好的阅读器不应该让你意识到它的存在。
> 它只负责把字排好，把光调对。

### 一些细节

- 行距按中文习惯放宽到 1.75 倍
- 段落间距独立于行距，读起来有呼吸感
- 代码块有语言角标，可以一键复制

- [x] 支持任务列表
- [x] 支持表格
- [ ] 支持数学公式（后续）

## 代码高亮

```rust
use mojuan_core::doc;

/// 解析 Markdown 并统计字数
fn analyze(text: &str) -> doc::Doc {
    let doc = doc::parse(text, None);
    println!("{} 字，约 {} 分钟", doc.stats.chars, doc.stats.minutes);
    doc
}
```

```js
const reader = new FileReader();
reader.onload = (e) => {
  const text = e.target.result;
  console.log(`loaded ${text.length} chars`);
};
```
